Nitro  Sept 30, 2026

New File Upload limit for Nitro

Discord has rolled out an update to the file upload limit for Nitro Users

The file(s) size limit is now up to 1 GB instead of 500 MB. The limit for Non-Nitro members and boosted servers stay the same.
