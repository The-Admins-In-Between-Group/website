Server Redesign on Mobile

↺ - Updated article. Review the changes under the article.

After years of requesting, Discord has finally redesigned the server settings to bring Automod configuration (amomng others) to mobile.

(⚠️ This has not been officially announced, this is just from an engineer that worked on it so there is no ETA and is subject to change.)

↺ Update (Sept 22, 2026): Redesign launched on Alpha/Beta

The redesigned server settings on mobile has been released to all users on the Alpha/Beta version of Discord and will soon be released to stable (no ETA).

↺ Update (Oct 4, 2026): Redesign launched on stable

The redesigned server settings on mobile has been released to all users on the stable version of Discord.
