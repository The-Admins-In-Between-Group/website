Quality of Life  Aug 13, 2026

New File Upload limit

↺ - Updated article. Review the changes under the article.

Discord has updated the file upload limit for all non-Nitro users.

The file(s) size limit is now up to 20 MB from 10 MB. The limit for Nitro users and boosted servers stay the same.

↺ Update (Sept 30, 2026): New File Upload limit for Nitro users

Discord has also updated the file upload limit for Nitro users.

The file(s) size limit is now up to 1 GB from 500 MB. The limit for boosted servers stay the same.
