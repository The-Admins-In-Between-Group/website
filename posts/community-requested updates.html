Quality of Life  May 25, 2026 - Sept 16, 2026

Community Requested Updates

⭐️ - This article covers all the community requestd updates that discord pushed as part of their 11th birthday celebrations. You can read about it in detail in the Blog Post article and post your own suggestions in Discord Town Hall.

Pinned DMs on Desktop

Discord has added the ability to pin direct messages to the top. The pinned DMs sync across all devices.

Pinned Channels in Servers

Discord has added the option to pin channels to the top of the channel list in servers. The pinned channels sync across all devices.

Sticky Search Pagination

Discord has improved upon search pages by making the navigation bar housing the pages stick at the bottom. Users can now easily navigate through search pages without having to scroll all the way to the bottom.

Mod View Improvements

Discord has made a few improvements to Mod View. They're as follows:

  • Non-server members, including those who have been kicked or banned are now viewable in Mod View to preserve past cases.
  • Audit Log is now also accessible from Mod View so the past mod cases of each user is now visible directly on a user's profile.

Friends Since

Users can now see how long they've been friends with each other on their profiles.

Duplicate Roles

Discord has added an option to duplicate roles. They function exactly like duplicating channels, carrying over all the permissions and settings.

Attachment Editing

Discord has added the option to edit attachments after they've been sent. Users can edit the alternate description as well as mark/unmark them as spoilers. Users cannot add attachments to regular messages.

Full View Profile Photos

Users can now view profile photos in full view.

Prune Permissions

Discord has added an option for server owners to restrict pruning inactive members to Admins only. Users can find the option in Server Settings > Safety Setup.

Webhooks on Mobile

Discord has added the option to create webhooks in server settings on mobile

QoL updates on Mobile

Discord has made a few quality of life updates on mobile such as being able to see timestamps on edits, a jump to top button in Forum posts and being able to copy user IDs from ban list.

Onboarding Integration update

If a server has Twitch or Youtube integration, admins now have an option to add it to Server Onboarding so new members joining will automatically be prompted to connect their accounts.

GIF Improvements

Discord has added a search bar in the Favorite GIFs section as well as an option to copy GIF links (right click/hold to copy).

Slash Command Improvements

Discord has made improvements and fixes to slash commands:

  • String options now support multiline input
  • Command autocomplete now has fuzzy search, so you can skip letters or type "/r a" to find "/role add"
  • Input is now saved to client even when users switch channels
  • Fixed typing space while typing subcommands making the command picker disappear
  • Fixed typing space to select a command sometimes selecting the wrong command
  • Fixed slash command user options sometimes failing to find the user
